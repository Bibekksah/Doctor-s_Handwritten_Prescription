# AI-Based Handwritten Medical Prescription Recognition

## Project Objective

Develop an AI-based system that recognizes handwritten
medicine names from prescription images and verifies the
recognized medicine against a reference database.

The system will also investigate optimized deployment
of the ML model using Docker and cloud computing.

## Main Pipeline

Prescription Image
    ↓
Image Preprocessing
    ↓
Handwritten OCR
    ↓
Medicine Name Extraction
    ↓
Medicine Verification
    ↓
Confidence Score
    ↓
  FastAPI
    ↓
  Docker
    ↓
  Cloud
